# 2 说明

## 2.1 EpClient接口请求工具

```text
	接口请求的调用工具为EpClient。每个接口对应一个Request的实现类，例如UserLoginRequest。Reqeust可通过构造或者setter的方式传入参数，点击到对应的实现类中会有参数说明注释。

	一些接口请求时需要登录状态并且设置患者，因此一般EpClient使用时要先调用登录UserLoginRequest接口（当前的EpClient对象会维持登录session），再调用设置患者GuineaPigSetCurrentRequest接口。EpClient的构造参数init_user_status=True则会自动完成以上步骤（登录的账号和患者信息有默认值，或可通过程序入口同级目录下的config.ini进行配置）。

	EpClient的请求接口方法有三个分别对应不同返回值
    	字符串：do_action（xxxRequect）
    	dict json数据：do_action_json(xxxReqeust)
    	对象：do_action_bean(xxxReqeust).to_result_data()
    	
    全局创建一个EpClient，不需频繁创建
```

## 2.2 EpWebSocketClient--EPStudio推送对应的客户端

```text
    上位机EPStudio中的设备列表信息以及采集数据，都是通过Websocket推送到客户端的，因此sdk中EpWebSocketClient就是用来接收推送的数据。

    此客户端可单独创建并调用start方法启动，或者创建之后当EpClient的构造参数websocket_client，EpClient实例化后会自动启动此客户端。

    此客户端开启之后会一直保持运行状态，若请求其他接口那么需要再启程序去请求，或者在当前程序中通过外部逻辑去控制。

    数据的接收回调函数通过EpWebSocketClient的构造函数传入。on_xxx分别对应几种类型的回调。event_msg参数需要EventMessage的实现类，是对几种on_xxx的封装。on_xxx的返回参数是json类型，event_msg的返回参数会解析成对应对象。传入event_msg后，on_xxx会失效。
    
    全局创建一个EpWebSocketClient，不需频繁创建
```

# 3 快速使用

## 3.1 单独接口请求

### 3.1.1 方式一：手动控制登录

```python
from epstudiosdk.client import EpClient
from epstudiosdk.request.user.UserLoginRequest import UserLoginRequest
from epstudiosdk.request.guineapig.GuineaPigSetCurrentRequest import GuineaPigSetCurrentRequest
from epstudiosdk.request.guineapig.GuineaPigGetCurrentRequest import GuineaPigGetCurrentRequest

# 1.创建请求 client
c = EpClient()
# 2.创建登录请求参数 request
userLoginRequest = UserLoginRequest('admin', 'admin')
# 3.调用接口
res = c.do_action_json(userLoginRequest)
print(res)
# 4.创建设置患者请求参数 request
setUser = GuineaPigSetCurrentRequest('20220526')
# 5.调用接口
res = c.do_action_json(setUser)
print(res)
# 6.请求其他接口
# 查询当前患者
res=c.do_action_bean(GuineaPigGetCurrentRequest()).to_result_data()
print(res.data)
```

## 3.4 EpWebSocketClient客户端

### 3.4.1 方式一：字符串回调

```python
from epstudiosdk.websocketclient import EpWebSocketClient

def on_message(ws, message):
    """
    webSocketClient 消息推送回调函数，告警推送、数据导出出错推送、设备链接信息推送等
    """
    print("### on_message ###")
    print(type(message))
    print(message)


def on_data(ws, data):
    """
    webSocketClient 数据推送回调函数
    格式说明：
        timestamp: 时间戳
        dataType：推送数据类型  EP采集数据   EPSpectrum频谱分析数据
        data：详细数据
        1.采集数据 {'timestamp': 1677047559693, 'dataType': 'EP', 'data': [{'deviceId': 'F9:DC:B2:3E:B4:BD', 'timestamp': 1677047559553, 'data': {'1': [-5.18e-43, -2.5851e-41]}, 'performance': {'packageLossRate': 0}}]}
        data: [{'deviceId': '设备ID', 'timestamp': 时间戳, 'data': {'通道号': [采集数据数组列表]}, 'performance': {'packageLossRate': 丢包率}}]
        2.频谱分析数据 {'timestamp': 1677047775194, 'dataType': 'EPSpectrum', 'data': {'haveData': True, 'range': [[0.0, 999.02], [-184.95, -99.3]], 'list': [{'deviceId': 'F9:DC:B2:3E:B4:BD', 'data': {'1': [[0.0, -144.03], [0.98, -138.67]]}}]}}
        data: {'range': [[x轴最小值, x轴最大值], [y轴最小值, y轴最大值]], 'list': [{'deviceId': '设备ID', 'data': {'通道号': [[x轴1, y轴1], [x轴2, y轴2]]}}]}
    """
    print("### 采集数据 ###")
    print(data)
    if data['dataType'] == 'EPSpectrum':
        print(data)
        print(len(data['data']["list"]))
        print(data['data']["range"])


def on_error(ws, error):
    """
    webSocketClient 链接错误回调函数
    """
    print("### on_error ###")
    print(error)


def on_close(ws, close_status_code, close_msg):
    """
    webSocketClient 关闭回调函数
    """
    print("### on_close ###")
    print(close_status_code)
    print(close_msg)


def on_open(ws):
    """
    webSocketClient 打开回调函数
    """
    print("### on_open ###")
    print("Opened connection")


# 2.创建socketclient，参数都是非必填项
socketClient = EpWebSocketClient(on_message=on_message, on_data=on_data, on_open=on_open, on_close=on_close, on_error=on_error)
# 3.开启客户端
socketClient.start()
# 4.停止客户端
# socketClient.stop()

# EpWebSocketClient可以作为参数传入EpClient中，EpClient会隐式启动socketClient
# EpClient(websocket_client=socketClient)
```

### 3.4.2 方式二：封装对象回调

```python
from epstudiosdk.websocket.websocket import EventMessage
from epstudiosdk.websocket.bean import *
from epstudiosdk.websocketclient import EpWebSocketClient


class MyEvent(EventMessage):
    """
    通过实现EventMessage接口，接收数据自动转换
    """
    def on_message(self, message: Union[str, dict, MessageReceive]):
        if isinstance(message, MessageReceive):
            print(message.type)
            if message.type == MessageType.DEVICE:
                for item in message.msg:
                    print("%s , %s" % (item.address, item.name))
            elif message.type == MessageType.CAMERA:
                for item in message.msg:
                    print("%s , %s" % (item.type, item.name))
            elif message.type == MessageType.WARN:
                print("%s , %s" % (message.msg.deviceId, message.msg.alarmContent))
            else:
                print(message.msg)
        pass

    def on_data(self, data: Union[str, dict, DataReceive]):
        if isinstance(data, DataReceive):
            print("%s , %s" % (data.timestamp, data.dataType))
            if data.dataType == DataType.EP:
                for item in data.data:
                    print("%s , %s , %s , %s" % (item.deviceId, item.performance, item.timestamp, item.data))
            elif data.dataType == DataType.EPSpectrum:
                print("%s , %s" % (data.data.range, data.data.list))
                for item in data.data.list:
                    print("%s , %s" % (item.deviceId, item.data))
            else:
                print(data.data)
        else:
            print(type(data))
            print(data)
        # pass

    def on_error(self, error):
        print(type(error))
        print(error)

    def on_close(self, close_status_code, close_msg):
        print(close_status_code)
        print(close_msg)

    def on_open(self):
        print("open")

# 2.创建socketclient，参数都是非必填项
socketClient = EpWebSocketClient(event_msg=MyEvent())
# 3.开启客户端
socketClient.start()
# 4.停止客户端
# socketClient.stop()
```

### 5.1.1 修改全局配置信息
```python
from epstudiosdk.request.appconfig.AppConfigPutRequest import AppConfigPutRequest

AppConfigPutRequest(pre_process_enabled=None,pre_process_algorithm=None,pre_process_threshold=None,pre_process_queue_size=None,debug_calculate_index=None,filter_enabled=None,filter_global=None,adapters=None,log_data_enabled=None)
""" 修改全局配置信息
    pre_process_enabled：是否启用信号预处理，非必填
    pre_process_algorithm：预处理信号算法 1、2，非必填
```
